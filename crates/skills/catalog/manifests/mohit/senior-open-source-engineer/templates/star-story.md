# STAR Story Template

Use this template to turn a real contribution into an interview-ready story.

## Template

```md
### Situation
<What repository, subsystem, or contribution context were you working in?>

### Task
<What problem needed to be solved? What constraints mattered?>

### Action
- <How you investigated the problem>
- <How you identified root cause or ownership>
- <Why you chose the implemented solution over alternatives>
- <How you validated the change>

### Result
<What improved? Include mergeability, stability, test coverage, maintainability, or reviewer feedback if measurable business impact is unavailable.>
```

## Guidance

- Keep it truthful and concrete.
- Focus on engineering judgment, not raw effort.
- Highlight tradeoffs, constraints, and repository adaptation.
- Use one story per real contribution.
