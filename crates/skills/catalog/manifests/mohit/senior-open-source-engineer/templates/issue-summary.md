# Issue Summary Template

Use this template to restate the task before implementation.

```md
## Issue Summary

### Problem
<What is broken, missing, or risky?>

### Expected Behavior
<What should happen instead?>

### Scope
<What is in scope for this change? What is explicitly out of scope?>

### Suspected Ownership
<Which module, layer, or subsystem likely owns the behavior?>

### Evidence Collected
- <doc, test, log, or code path>
- <doc, test, log, or code path>

### Open Questions
- <only include unresolved items that materially affect implementation>
```

## Rules

- Keep it short.
- Base it on repository evidence.
- Use repository terminology.
- Distinguish facts from hypotheses.
